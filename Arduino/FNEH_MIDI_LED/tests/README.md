# FNEH_MIDI_LED Tests

This directory contains unit tests for the FNEH_MIDI_LED Arduino project.

## Running Tests

1. Install the ArduinoUnit library through the Arduino Library Manager
2. Open the test sketch in Arduino IDE
3. Upload to your Arduino board
4. Open the Serial Monitor to view test results

## Test Structure

- `test_led_functions.ino`: Tests for LED control functions
- `test_midi_handling.ino`: Tests for MIDI message handling
